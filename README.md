# CPP Student Management System

A simple C++ console application for managing student records using Object-Oriented Programming (OOP) concepts.

## Features
- Add student records (ID, name, and grades).
- Display all students in a formatted view.
- Search and update student information.
- Basic input validation using `cin.fail()`.

## Tech Stack
- **Language:** C++
- **Key Concepts:** Classes & Objects, Vectors, Input Validation.

## How to Run
Compile `main.cpp` using any C++ compiler (like g++) and run the output executable:

```bash
g++ main.cpp -o app
./app
